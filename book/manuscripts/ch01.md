# PS5 であったボードコンピューター AMD-BC-250

最近、AMD-BC-250 を購入しました。

![AMD-BC-250](./images_ch01/20260130131413.jpg)

## CPU 製造の背景

一般に Core i7 や i5 など、CPU にはグレードがあります。最初から i5 モデルとして製造するわけではなく、製造後の検査結果によって上位・下位モデルに分類されて販売されます。

これは他のコアでも同様ですが、ゲーム機が対象のコアだと事情が変わります。ゲーム機にいくつかモデルがあれど同製品であれば、性能は一般的に同一です。なお、Xbox Series X|S は X と S でコアに性能差があります。この製造の過程で発生する不良コアを再利用してるのかもしれません。知らんけど。

## AMD-BC-250

少し遠回りになりましたが、AMD-BC-250 はこの背景と深く関係しています。AMD-BC-250 のコアは、PS5 向けに製造された APU の不良品を再利用したものといわれています [^broken-PS5]。

[^broken-PS5]: AMD is selling broken PlayStation 5 APUs to cryptominers, https://videocardz.com/newz/amd-is-selling-broken-playstation-5-apus-to-cryptominers

PS5 に下位モデルはないため、不良品はゲーム機には使えません。PS5 専用のカスタムチップであるため、通常の PC パーツとして流通させることもできません。

PS5 が発売された 2020 年は、暗号通貨マイニングブームの真っ只中でした。詳細な経緯は公表されていませんが、不良品は採掘向けのボードコンピューターとして転用され、その後 2024 年ごろから一般市場にも流れてきました。そのボードをついに私も手に入れました。

### 何に使えるか

コアが PS5 由来ということで、ゲーム性能に強みがあります。このボードをゲーム機として動かす記事や動画も多く公開されています。私もこの機種で遊んでみます。なお、すでに PS5 とゲーミング PC を持っているため、実用上は不要です。純粋に「面白そうだから」という動機で購入しました。

## セットアップ

まず電源設定を変更します。私が購入した機種の初期状態は、電源を接続すると自動起動するようになっていました。本体の電源ボタンで制御したいため、基板上の起動模式を切り替えるピン [^AUTO_PWRON1] をジャンパーで変更します。

![購入時の自動起動設定](./images_ch01/20260201120926.jpg){width=300}

設定ピンを変更した状態が次の画像です。これで電源ボタンによる on/off が有効になります。

![電源ボタンで起動するように電源設定した](./images_ch01/20260201120922.jpg){width=300}

[^AUTO_PWRON1]: AUTO_PWRON1, https://elektricm.github.io/amd-bc250-docs/hardware/pinouts/#auto_pwron1

### 電源装置の準備と加工

このボードには PCIe の 8 pin（6+2 pin）コネクタを利用して、電圧 12V、最小で 220W の電力供給が必要です。参考ドキュメント [^PowerSupply] を参考に、小型で取り回しやすい Flex ATX 規格の電源を選びました。

[^PowerSupply]:Power Supply Requirements, https://elektricm.github.io/amd-bc250-docs/hardware/power/#basic-requirements

![Metalfish 550W FlexATX（全体）](./images_ch01/20260201125550.jpg){width=300}

Metalfish 550W FlexATX を採用しました。この電源から PCIe 用の 8 ピンをボードに接続します。Flex ATX 電源を PC 外で单体動作させるには、通常はマザーボードが担う電源 ON 信号を擬似的に送る必要があります。電源コネクタの指定ピンを針金によりショートさせて対応しました。

![マザボ向けピンをショートさせる](./images_ch01/20260201125206.jpg){width=300}

針金が外れて他と接触しないよう、ショート部分をカプトンテープで絶縁保護しました。接触が不安定になりやすいので、市販のショートソケットに切り替えています。

![ショートさせた部分を保護した](./images_ch01/20260201125154.jpg){width=300}

### ファン

このボードは発熱が大きいです。先駆者の記事や動画を参考に、ヒートシンクの側面に送風するシロッコファンと、上部に載せる 12 cm ファンの 2 段構成にしました。

シロッコファンは基板上のピンと干渉しやすく、送風口とヒートシンクの高さ位置も一致しないため固定が難しいです。今回はカプトンテープで仮固定し、なるべく送風ロスが出ないよう位置を調整しました。

![採用したシロッコファン](./images_ch01/20260201123750.jpg){width=300}

12 cm ファンはヒートシンク上部に置くだけの簡易構成です。固定はしていません。

![採用した 12 cm ファン](./images_ch01/20260201123740.jpg){width=300}

冬の室温 12℃・暖房なしの環境で、アイドル時の CPU 温度はおよそ 42℃ でした。ベンチマーク中は 53℃ 前後まで上昇するため、ゲームを継続的に遊ぶ用途では冷却の強化が必要です。

### 起動

ボード本体に電源とファン、そしてモニタに接続しました。

![ボードに必要最低限のパーツを接続した](./images_ch01/20260201121543.jpg){width=300}

無事に BIOS 画面の起動を確認しました。

![BIOS 画面（起動確認）](./images_ch01/20260201121848.jpg){width=300}

次は OS のインストールです。M.2 SSD とインストール用の USB メモリを接続します。

![M.2 SSD と USB メモリを接続（全体）](./images_ch01/20260201121937.jpg){width=300}

![M.2 SSD と USB メモリを接続（アップ）](./images_ch01/20260201122001.jpg){width=300}

このボードは Windows に対応していないため、ゲーミング向けの Linux ディストリビューション「Bazzite」をインストールしました。イメージのダウンロード時に GPU として「AMD RX4xx+」を選択し、インストール途中でブートローダーに「grub2」を選択するのが重要なポイントです。それ以外は通常の Linux インストールと同じ流れで問題ありません。

![Bazzite インストール完了](./images_ch01/20260201122026.jpg){width=300}

Bazzite のインストールは無事に完了しました。

### ベンチマーク

Steam 経由でモンスターハンターワイルズのベンチマークソフトをインストールし、計測を実施しました。

![モンハンベンチマーク（計測開始）](./images_ch01/20260201135605.jpg){width=300}

ベンチマーク実行中はファンが高回転になり、ヒートシンクからの排気温度も上昇します。

![モンハンベンチマーク（計測中）](./images_ch01/20260201135618.jpg){width=300}

ベンチマークは最後まで完走しました。

![ベンチマーク完走](./images_ch01/20260201135642.jpg){width=300}

スコアは 9984、平均 60fps でした。冷却は仮構成、電源はピンショートの代用設定という状況を考えると、十分な結果です。画質設定を調整すればゲームとしても動作しそうです。なお、ベンチマーク中の CPU 温度はおよそ 53℃ でした。

### まとめ

この章では AMD-BC-250 を動かすところまでをひととおり試しました。ベンチマークは問題なく完走し、起動・ゲーム動作ともに確認できました。

課題として残るのは冷却と収納です。一般的な PC ケースに対応した形状ではないため、ファンの固定やケースへの組み込みを別に考える必要があります。3D プリンターで専用マウントを自作している例もありますが、次章で検討していきます。
